# 네컷 사진관 📸 — 캐논 SELPHY 4×6 인쇄 + QR 다운로드

실제 네컷 사진 부스처럼 **촬영 → 사진 고르기 → 테두리·필터 → 4×6 인쇄 → QR로 휴대폰 저장**까지 되는 웹사이트예요.

**사이트 주소: https://sungwhikung.github.io/photobooth/**

## 파일 (폴더 없이 전부 한 곳에)
| 파일 | 하는 일 |
|---|---|
| `index.html` | 사진관 화면 (사진관 PC에서 실행) |
| `booth.js` / `booth.css` | 촬영 · 합성 · 인쇄 · QR 업로드 |
| `download.html` / `download.js` / `download.css` | QR을 찍으면 휴대폰에서 열리는 사진 받기 화면 |
| `qrcode.js` | QR 코드 만들기 (MIT 라이선스, kazuhikoarase/qrcode-generator) |
| `sw.js` | 인터넷이 잠깐 끊겨도 사진관 화면이 열리게 해 줌 |
| `start_booth_windows.bat` | 윈도우: 전체 화면 + 인쇄 창 없이 바로 인쇄 |
| `start_booth_mac.command` | 맥용 실행 파일 |

GitHub 저장소 맨 위에 **파일 전부를 그대로** 올리면 돼요. 같은 이름은 덮어써져요.

## ① Cloudinary 업로드 프리셋 만들기 (QR에 꼭 필요, 1분)
QR로 사진을 받으려면 사진을 Cloudinary(무료)에 올려야 해요. Cloud name `y8ws9zmi`는 이미 코드에 들어 있어요.

1. https://console.cloudinary.com/app/settings/upload/presets 접속 (로그인)
2. **Add Upload Preset** 클릭
3. **Upload preset name**: `fourcut` (정확히 이렇게)
4. **Signing mode**: **Unsigned** ← 가장 중요
5. 폴더(Asset folder)·Public ID 접두사는 **비워 두기** → **Save**

> (선택) 보안을 더 높이려면 같은 화면에서 Allowed formats를 `jpg, mp4, webm`으로 제한하세요.

## ② GitHub에 올리기
1. 저장소에서 **Add file → Upload files** → 파일 전부 선택 → **Commit changes**
2. **Settings → Pages**에서 Branch `main`, 폴더 `/(root)` → Save (이미 했다면 생략)
3. 2~3분 뒤 https://sungwhikung.github.io/photobooth/ 열어서 확인

## ③ 사진관 PC 준비
1. 캐논 SELPHY 드라이버 설치 → USB/Wi-Fi 연결
2. Windows 설정 → 프린터 및 스캐너 → “Windows에서 기본 프린터 관리” **끄기** → Canon SELPHY **기본값으로 설정**
3. Canon SELPHY → 인쇄 기본 설정: 용지 **엽서(100×148mm)**, 방향 **세로**, **테두리 없음**
4. 이 저장소의 `start_booth_windows.bat`을 사진관 PC에 받아 두세요 (사이트 주소가 이미 들어 있어요)
5. 크롬을 모두 닫고 bat 파일 더블클릭 → 전체 화면으로 열림 (끄기: `Alt + F4`)
6. (선택) 부팅하면 자동 실행: `Win + R` → `shell:startup` → 열린 폴더에 bat 파일 바로가기 넣기

## ④ 행사 전 점검 (시작 화면에서 **S** 키 → 관리자 설정)
맨 위 **상태 점검**에 전부 ✔가 뜨는지 확인하세요.
- ✖ “프리셋이 없어요” → ①을 다시 확인
- **4×6 테스트 인쇄** → 파란 점선이 잘리면 “인쇄 크기 보정”을 97~98로
- **QR 업로드 테스트** → 화면의 QR을 휴대폰으로 찍어 분홍색 “QR 테스트 성공!”이 보이면 OK
- 손님처럼 처음부터 끝까지 한 번 찍어 보기

## 기능
- **실제 네컷 흐름**: 프레임·장수 선택 → 10초 카운트다운 8컷 (셔터 소리·플래시·찍힌 사진 잠깐 보여 주기) → 4장 고르기 → 테두리 11종 + 필터 6종 + 문구·날짜 → 인쇄
- **즉시 QR**: 사진이 올라가기 전에 QR이 바로 떠요. 받기 화면이 사진이 올라올 때까지 기다렸다가 보여 줘요.
- **사진에 QR 인쇄**: 실제 네컷처럼 사진 아래에 QR이 들어가요 (스트립 13.9mm, 그리드 17.4mm). 설정에서 끌 수 있어요.
- **움직이는 네컷**: 고른 4컷의 셔터 직전 3초를 영상(MP4)으로 만들어 함께 제공
- **인터넷이 끊겨도 OK**: 사진은 PC에 보관했다가 인터넷이 돌아오면 자동으로 올라가요 (시작 화면 아래 “업로드 대기 N”). 촬영·인쇄는 인터넷 없이도 계속돼요.
- **용지 크기**: SELPHY 용지(100×148mm, 기본) / 정확한 4×6 인치(101.6×152.4mm) 선택
- **커스텀 프레임**: 학교·행사 로고 프레임. 설정에서 템플릿을 받아 디자인 → 1200×1800 그림으로 추가. 사진 칸을 투명하게 뚫은 PNG면 장식이 사진 위에 올라가요.
- **행사 이름**: 시작 화면 제목 + 사진 아래 작은 글씨
- **음성 안내**: 한국어 음성이 있는 PC에서 “포즈를 취해 주세요” 등 안내
- **남은 용지 세기**: 남은 장수를 넣으면 인쇄할 때마다 줄고, 5장 이하면 경고
- **카메라가 빠졌다 다시 꽂혀도** 그 컷부터 다시 찍어요.

## 보안 · 개인정보
- 받기 화면은 **Cloudinary의 `fourcut` 폴더 사진만** 열어요. 다른 주소를 끼워 넣은 가짜 링크는 “잘못된 주소”로 막혀요.
- 사진 번호는 무작위 10글자라 추측할 수 없고, 주소의 `#` 뒤 정보는 GitHub 서버로 전송되지 않아요.
- 정해진 곳(Cloudinary 등) 외에는 데이터가 나가지 않도록 Content-Security-Policy로 막혀 있어요.
- 받기 화면에 “○월 ○일까지 받을 수 있어요” 안내 (설정의 “사진 받기 가능 기간”, 기본 7일).
- **행사가 끝나면** Cloudinary → Media Library → `fourcut` 폴더를 지워 주세요 (자동 삭제되지 않아요).
- 관리자 비밀번호로 설정 화면을 잠글 수 있어요. 설정값은 그 PC에만 저장돼요.
- 업로드 프리셋 이름은 공개 코드에 들어 있으니, 원하면 ①의 Allowed formats 제한을 걸어 두세요.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 시작 화면에 “⚠ QR 설정 필요” | S키 → 상태 점검의 안내대로 프리셋 만들기 |
| 휴대폰에서 “사진이 아직 준비되지 않았어요” | 사진관 PC 인터넷 확인. 연결되면 자동으로 올라가니 잠시 후 “다시 시도” |
| 인쇄 창이 떠요 | 크롬을 완전히 끄고(작업 표시줄 아이콘까지) bat 파일로 다시 실행 |
| 사진 가장자리가 잘려요 | 테스트 인쇄 후 크기 보정 97~98% |
| 카메라가 안 켜져요 | 줌 등 다른 프로그램 끄기, 설정에서 카메라 고르기 |
| GitHub에 새로 올렸는데 예전 화면이 나와요 | 2~3분 기다린 뒤 설정의 “새로고침” |
| 카카오톡으로 QR을 찍었더니 저장이 안 돼요 | 받기 화면 위의 “기본 브라우저로 열기” |
