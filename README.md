# 네컷 사진관 📸 — 캐논 SELPHY 4×6 인쇄 + QR 다운로드

실제 네컷 사진 부스처럼 **촬영 → 사진 고르기 → 테두리·필터 → 4×6 인쇄 → QR로 휴대폰 저장**까지 되는 웹사이트입니다.

## 파일 구성 (폴더 없이 전부 한 곳에)
```
index.html              사진관 화면 (키오스크 PC에서 실행)
download.html           QR 코드를 찍으면 휴대폰에서 열리는 사진/영상 받기 페이지
booth.css / booth.js    사진관 화면 스타일 / 촬영·합성·인쇄·QR 업로드
download.css / download.js  받기 페이지 (허용된 저장소 주소만 열림)
qrcode.js               QR 코드 생성 라이브러리 (MIT, kazuhikoarase/qrcode-generator)
start_booth_windows.bat 윈도우용 키오스크 실행 (바로 인쇄 모드)
start_booth_mac.command 맥용 키오스크 실행
```
모든 파일을 저장소 최상단에 그대로 올리면 됩니다.

## 진행 순서
1. 화면 터치 → 2. 프레임(네컷 스트립 2×6 ×2줄 / 2×2 그리드)과 장수 선택
3. 촬영: 컷마다 10초 카운트다운, 총 8컷
4. 8장 중 4장 고르기 (60초 제한)
5. 테두리 11종 · 필터 6종 · 문구 · 날짜 (60초 제한)
6. 인쇄하기 → 자동 인쇄 + 화면에 QR 코드
   - QR을 찍으면 **사진**과 **움직이는 네컷 영상**(셔터 직전 3초, MP4)을 휴대폰에 저장할 수 있습니다.

## 1. 캐논 프린터 설정 (처음 한 번)
1. SELPHY 드라이버 설치 후 USB/Wi-Fi 연결
2. Windows 설정 → 프린터 및 스캐너 → "Windows에서 기본 프린터 관리" **끄기** → Canon SELPHY **기본값으로 설정**
3. Canon SELPHY → 인쇄 기본 설정: 용지 **엽서(100×148mm) / 4×6**, 방향 **세로**, **테두리 없음**

## 2. 사진관 PC에서 실행
1. `start_booth_windows.bat`을 메모장으로 열고 `BOOTH_URL=` 뒤에 GitHub 사이트 주소를 넣고 저장
   ```
   set "BOOTH_URL=https://내아이디.github.io/저장소이름/"
   ```
2. 더블클릭 → 전체 화면 키오스크로 열리고, 인쇄 시 **인쇄 창 없이 바로 캐논으로 출력**
3. 종료: `Alt + F4`

> GitHub 사이트(https)로 실행해야 QR이 예쁜 받기 페이지(download.html)로 연결됩니다.
> 로컬 파일로 실행하면 QR이 사진 파일 주소로 바로 연결됩니다.

## 3. 관리자 설정 (⚙ 버튼 또는 S 키)
| 항목 | 설명 |
|---|---|
| 카메라 / 좌우 반전 | 여러 카메라 중 선택, 거울 모드 |
| 카운트다운 · 컷 수 · 제한시간 | 부스 운영 방식에 맞게 |
| 인쇄 크기 / 위치 보정 | **4×6 테스트 인쇄**로 확인 후 조정 (잘리면 97~98%) |
| 사진 업로드 방식 | QR 다운로드용 임시 저장소 (아래 참고) |
| 움직이는 네컷 영상 | 켜면 영상도 함께 제공 |
| 관리자 비밀번호 | 손님이 설정을 못 바꾸게 잠금 |
| QR 업로드 테스트 | 업로드가 잘 되는지 미리 확인 |

설정값(API 키, 비밀번호 포함)은 **그 PC의 브라우저에만 저장**되고 GitHub 코드에는 들어가지 않습니다.

## QR 다운로드 저장소 선택
GitHub Pages는 파일 업로드를 받을 수 없는 정적 사이트라서, 사진을 잠깐 올려 둘 외부 저장소가 필요합니다.

| 방식 | 준비 | 보관 | 영상 |
|---|---|---|---|
| **tmpfiles.org** (기본) | 없음 | 60분 후 자동 삭제 | ✅ |
| **ImgBB** | api.imgbb.com 무료 API 키 | 1시간~30일 선택 | ❌ 사진만 |
| **Cloudinary** | 무료 가입 → Settings → Upload → *Unsigned* upload preset 생성 | 직접 삭제 전까지 | ✅ |
| 사용 안 함 | — | — | — |

행사장에서 오래 안정적으로 쓰려면 Cloudinary를 추천합니다. 시작 전에 꼭 **QR 업로드 테스트**를 눌러 확인하세요.

## 보안 · 개인정보
- 사진은 인쇄용 처리 모두 PC 안에서 하며, QR을 켰을 때만 선택한 저장소로 **사진 1장(+영상 1개)**이 올라갑니다.
- 파일 이름에 무작위 문자열이 붙어 주소를 추측하기 어렵고, tmpfiles는 60분 뒤 자동 삭제됩니다.
- 받기 페이지는 **허용된 저장소(tmpfiles / ImgBB / Cloudinary) 주소만** 열어서, 다른 주소를 끼워 넣은 가짜 링크로 악용할 수 없습니다.
- Content-Security-Policy로 정해진 곳 외에는 스크립트 실행·데이터 전송이 막혀 있습니다.
- 받기 페이지는 검색엔진에 노출되지 않도록 `noindex` 처리되어 있습니다.
- 관리자 비밀번호로 설정 화면을 잠글 수 있습니다.

## 문제 해결
- **카메라가 안 켜져요** → 다른 프로그램(줌 등)이 카메라를 쓰고 있지 않은지 확인, 설정에서 카메라 선택
- **인쇄 창이 떠요** → bat 파일로 실행했는지, 크롬이 그 전에 완전히 꺼져 있었는지 확인
- **사진 가장자리가 잘려요** → 테스트 인쇄 후 크기 보정을 97~98%로
- **QR을 못 만들었다고 나와요** → 인터넷 연결 확인, 관리자 설정에서 업로드 방식을 다른 것으로 바꿔 테스트
